# Asset provenance

`mod/thumbnail.jpg` was generated specifically for Guild Feed Box Sync using
OpenAI image generation on 2026-08-09, then resized to 512 by 512 pixels for the
Workshop package. It is based on Palworld's Feed Box icon from the
[Palworld Wiki](https://palworld.wiki.gg/images/Feed_Box_icon.png) so the mod is
visually identifiable as operating on the vanilla Feed Box. The generated
thumbnail adds the synchronization arrows and dark background; it contains no
Palworld logo or characters.
