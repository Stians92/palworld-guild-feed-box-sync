# Security Policy

## Supported Versions

Security fixes are provided for the latest published version when practical.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Older versions | No |

## Reporting a Vulnerability

Use GitHub's private **Report a vulnerability** form on this repository's
Security page. Do not open a public issue containing exploit details.

Private reports are appropriate for issues such as:

- Food moving between different guilds
- Item duplication, deletion, or unauthorized inventory changes
- Crashes that another player can trigger remotely
- Crafted game or network state that bypasses the mod's ownership checks

Include the mod and Palworld versions, hosting setup, reproduction steps,
expected and observed behavior, and the smallest relevant set of
`[GuildFeedBox]` log lines. Do not attach saves, complete logs, or personal and
server information unless requested.

If private vulnerability reporting is temporarily unavailable, open a public
issue asking for a private contact channel without including vulnerability
details.

Reports will be assessed as time permits. This project does not promise a fixed
response or resolution time. Confirmed reports may be handled through a private
GitHub security advisory until a fix and disclosure are ready.
